# Kitforge

A creators hub for mobile suit model builders: community feed, chat, member profiles, commissions and a shop.

- Plain HTML/CSS/JS — no build step. Open `index.html` through any static web server.
- Accounts, posts, photos and chat run on Supabase. See [SETUP.md](SETUP.md).
- `serve.ps1` runs a local preview at http://localhost:8080 on Windows.
