# Hangar Bay Builders

A creators hub for mobile suit model builders: community feed, chat, member profiles and commissions.

- Plain HTML/CSS/JS — no build step. Live at https://hangar-bay-builders.netlify.app/ (deploys automatically from `main` via Netlify).
- Accounts, posts, photos and chat run on Supabase. See [SETUP.md](SETUP.md).
- `serve.ps1` runs a local preview at http://localhost:8080 on Windows.
